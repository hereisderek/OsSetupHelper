# notion

Notion workspace app.

- **macOS**: Homebrew Cask `notion`.
- **Windows**: winget `Notion.Notion`.
- **Linux**: not applicable. Notion has no official Linux desktop app — its download page lists only macOS and Windows, and every AUR package (`notion-app-electron`, `notion-desktop-git`, …) is a community wrapper/repack, not an official build. The previously used `notion-desktop` key was a community package name and was removed. Left blank deliberately.
