# wechat

WeChat (微信).

- **macOS**: Homebrew Cask `wechat`.
- **Windows**: winget `Tencent.WeChat` (official qq.com download).
- **Linux**: not wired up. Tencent ships an official native Linux client (since late 2024) but as direct .deb/.rpm/AppImage downloads from linux.weixin.qq.com — no distro default repo carries it and there is no vendor apt repo. Left blank deliberately rather than half-implemented.
