# jetbrains_toolbox

JetBrains Toolbox App (manages IntelliJ/PyCharm/Android Studio etc. installs).

- **macOS**: Homebrew Cask `jetbrains-toolbox`.
- **Windows**: winget `JetBrains.Toolbox`.
- **Linux**: not wired up. JetBrains's documented Linux install is their own tarball (jetbrains.com/help/toolbox-app); no distro default repo carries it (the snap is community-maintained, not JetBrains). Left blank deliberately rather than half-implemented.
