# freedownloadmanager

Download manager.

- **macOS**: Homebrew Cask `free-download-manager`.
- **Windows**: winget `SoftDeluxe.FreeDownloadManager` — verified against the winget-pkgs manifest (installer URL is freedownloadmanager.org itself). The previously used `FreeDownloadManager.FreeDownloadManager` id does not exist in winget.
- **Linux**: not wired up. No distro packages FDM in its default repos; official Linux builds are direct .deb/.rpm downloads from freedownloadmanager.org with no repository. Left blank deliberately — the centralized installer gracefully no-ops on Linux.
