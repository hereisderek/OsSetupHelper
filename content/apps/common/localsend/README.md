# localsend

LocalSend — open-source cross-platform local file sharing (AirDrop-like).

- **macOS**: Homebrew Cask `localsend`.
- **Windows**: winget `LocalSend.LocalSend` (official GitHub release binaries).
- **Linux**: not wired up. LocalSend distributes .deb/.rpm/AppImage straight from GitHub releases — not in any distro's default repos. Left blank deliberately rather than half-implemented.
