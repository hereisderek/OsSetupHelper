# sublime

Sublime Text editor.

- **macOS**: Homebrew Cask `sublime-text`.
- **Windows**: winget `SublimeHQ.SublimeText.4` (verified in winget-pkgs at manifests/s/SublimeHQ/SublimeText/4).
- **Linux**: not wired up. `sublime-text` exists only in Sublime HQ's own apt/dnf repo and the AUR — not in any distro's default repos. Left blank deliberately rather than half-implemented.
