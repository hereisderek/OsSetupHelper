# handbrake

Video transcoder.

- **macOS**: Homebrew Cask `handbrake`.
- **Windows**: winget `HandBrake.HandBrake` (verified in winget-pkgs; official GitHub release binaries).
- **Linux**: `handbrake`, verified present in Ubuntu's default repos (universe) and Arch's official `extra` repo. Fedora does not package it (RPM Fusion territory) — the centralized installer's rescue path prints a manual-install message there. HandBrake's own recommended Linux channel is Flathub, which doesn't fit this project's plain package-manager approach.
