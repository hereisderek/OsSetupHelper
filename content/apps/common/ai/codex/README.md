# codex

[OpenAI Codex](https://github.com/openai/codex) — terminal-based coding agent.

macOS: Homebrew Cask (`codex`). Linux/Windows: npm (`@openai/codex`, requires Node.js — pulled in automatically). Grouped under `apps/ai/` since it's an agentic coding tool like the others here, even though its actual install mechanism is CLI-style on non-mac platforms.
