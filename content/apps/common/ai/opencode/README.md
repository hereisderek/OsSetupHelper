# opencode

[OpenCode](https://opencode.ai/) desktop app. Distinct from the `opencode` CLI role under `cli/common/` (same underlying project, different install target).

macOS only here (Homebrew Cask). Windows/Linux builds exist upstream (opencode.ai/download) but have no verified package-manager identifier — install manually if needed, or extend `app_pkg_win`/`app_pkg_linux` once you've confirmed one.
