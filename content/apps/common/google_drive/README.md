# google_drive

Google Drive desktop client.

- **macOS**: Homebrew Cask `google-drive`.
- **Windows**: winget `Google.GoogleDrive`.
- **Linux**: not applicable. There is no official Google Drive desktop client for Linux. The previously used `google-drive-ocamlfuse` is a third-party FUSE filesystem client (also requiring a PPA), not an official build, and was removed. The key is blank deliberately.
