# macs_fan_control

Fan control for Macs (CrystalIDEA).

- **macOS**: Homebrew Cask `macs-fan-control`.
- **Windows/Linux**: not wireable. CrystalIDEA ships an official Windows build (crystalidea.com/macs-fan-control — aimed at Boot Camp), but there is **no winget package** (verified: winget-pkgs has no Macs Fan Control manifest; the publisher's only winget entries are AnyToISO/Speedyfox/UninstallTool) and no Linux version. Stays a macOS-only role until a verifiable winget id appears.
