# raycast

Raycast — extensible launcher / productivity tool.

- **macOS**: Homebrew Cask `raycast`.
- **Windows**: not wireable via this project's winget installer. Raycast for Windows is generally available (since late 2025), but it is distributed through the **Microsoft Store** and direct download only — Raycast requested removal of the community `Raycast.Raycast` manifest from winget-pkgs (issue #315392), so there is no winget id to use. Stays a macOS-only role.
- **Linux**: no version exists.
