# battgui

Modern battery management and limit GUI for Apple Silicon MacBooks (https://github.com/clzoc/BattGUI).

- **macOS**: downloaded directly from GitHub releases via `_shared_tasks/installer/mac_install_release.yml`.
- **Gatekeeper & Code Signing**: automatically remediated and locally ad-hoc signed so the app launches without security warnings.
- **Windows/Linux**: not applicable (macOS Apple Silicon specific).
