# mole

SSH tunnel tool (github.com/davrodpin/mole) — easily create SSH tunnels to remote services.

- **macOS**: installed from the project's own tap `davrodpin/mole/mole` (documented install path on davrodpin.github.io/mole). **Do not** switch this back to plain `mole`: the `mole` formula in homebrew-core is now an unrelated Mac-cleaner app (mole.fit) that reused the name after the original formula was removed.
- **Linux/Windows**: not in any distro's default repos — official distribution is GitHub release binaries only. Stays a macOS-only role.
